# DriveGuard — лендинг и демо

Готовый статический сайт. Сборка, npm, сервер приложения и API-ключи не нужны.
Демо содержит учебные сценарии, а не реальные биометрические записи.

## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub. Для бесплатного GitHub Pages выберите Public.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `styles.css`, `favicon.svg`, `.nojekyll`, папки `demo` и `validation`. Не загружайте одну внешнюю папку целиком: `index.html` должен оказаться в корне. Файл `.nojekyll` может быть скрыт в файловом менеджере; при загрузке через браузер его можно создать через Add file → Create new file.
3. Откройте Settings → Pages.
4. В Build and deployment → Source выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите Save.
6. Дождитесь завершения публикации. Ссылка появится в Settings → Pages.

Адрес сайта: `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
Демо: `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/demo/`.
Для репозитория `ВАШ-ЛОГИН.github.io` сайт открывается прямо в корне домена.

Все пути относительные: сайт работает и в корне домена, и внутри репозитория.
Главная страница → «Посмотреть демо» → приложение → логотип/«О проекте» → главная.

## Что включено

- `index.html`, `styles.css`, `favicon.svg` — лендинг с личным и коммерческим тарифами.
- `demo/` — интерактивный прототип: поездка, сценарии, сигналы, профиль, места отдыха, журнал.
- `validation/` — протокол проверки, открываемый из демо.
- `.nojekyll` — публикация файлов без обработки Jekyll.

Цены 199 ₽/месяц и 490 ₽/автомобиль/месяц — планируемая модель. Оплата не подключена.
Кабинет компании и отчёты не представлены как готовые функции.

## Проверка перед публикацией

Откройте `index.html` в браузере. Нажмите «Посмотреть демо», начните демо-поездку,
откройте «Сценарии», проверьте переходы между вкладками и возврат на лендинг.
После публикации выполняйте те же действия по адресу GitHub Pages.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
